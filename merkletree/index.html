📚 What is a Merkle Tree?

🔐 Leaf Nodes

The bottom layer contains hashes of your actual data. Each piece of data gets hashed using SHA-256.

🔗 Parent Nodes

Each parent node is created by hashing the concatenation of its two children's hashes.

🌿 Merkle Root

The topmost node contains a single hash that represents ALL data in the tree. Changing any data changes the root!

✅ Merkle Proofs

Prove that a specific piece of data is in the tree without revealing all data - just log(n) hashes needed!
